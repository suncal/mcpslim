# Contributing

Thanks for looking. This project is small enough that a good issue or a focused pull request is genuinely useful.

**Good ways to help**
- Open an issue describing a real problem you hit, with the command or input that caused it.
- Pick anything labelled `good first issue` or `help wanted`.
- Improve the README where it confused you. That counts.

**Pull requests**
1. Fork, branch from `main`, keep the change focused.
2. Run the test suite before you push (see the README for the command).
3. Describe what changed and why in the PR. A screenshot helps for anything visual.

Be kind in issues and reviews. Maintainers reply within a few days.
